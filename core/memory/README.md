# Memory

`decisions.md` company-wide decisions, newest on top. `follow-ups.md` dated promises. `reviews/` weekly reviews. `imported/` summaries of material pulled in from outside, each marked with its source. `actions.md` every action the brain took outside the brain, and what allowed it. `onboarding.json` interview progress. `install-receipts.md` what was installed when.

`decisions.md`, `actions.md`, `filed-meetings.md` and `install-receipts.md` only gain rows. To correct
one, add a new row that says what changed; never edit or delete an old one. That way two devices adding
rows at the same time keep both.
