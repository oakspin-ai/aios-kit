# Templates

The doctor's standard wording, one file per procedure or document. Each file holds the doctor's
usual text and placeholders in [square brackets]; patient details are added only in the
hospital's own system. Note the date the doctor last approved each file.

| Start from | For |
| --- | --- |
| [operation-note.md](operation-note.md) | Standard operation note for one procedure |
| [discharge-summary.md](discharge-summary.md) | Standard discharge text for one procedure |
| [patient-handout.md](patient-handout.md) | After-surgery instructions and follow-up schedule |
| [patient-replies.md](patient-replies.md) | Approved answers to common patient questions |
